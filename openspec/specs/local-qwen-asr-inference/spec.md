# local-qwen-asr-inference Specification

## Purpose

定义 SeaCraftASR 进程内直接运行 Qwen3-ASR 模型的推理运行时契约：本地权重加载与设备放置、内存音频直传与语种注入、原始输出解析与既有前缀格式的兼容、并发闸门语义、失败到对外错误码的映射，以及推理实例的加载状态与生命周期管理。

## Requirements

### Requirement: 从本地权重目录加载转写模型
系统 MUST 从配置的本地模型目录加载 Qwen3-ASR 权重与配套处理器，并放置到指定的 NPU 设备上。模型 MUST 使用多模态条件生成类而非纯因果语言模型类加载，MUST NOT 依赖因果语言模型的自动映射。

#### Scenario: 加载本地权重
- **WHEN** 服务的本地模型目录包含完整权重与处理器配置
- **THEN** 系统完成权重加载并放置到目标 NPU 设备，状态接口报告模型已加载及设备标识

#### Scenario: 模型目录缺失或权重不可读
- **WHEN** 配置的本地模型目录不存在、缺少权重文件或文件不可读
- **THEN** 首次触发该能力时返回 `4011`，并记录具体缺失路径，普通转写之外的其它健康能力不受影响

#### Scenario: 目标设备不可用
- **WHEN** 配置的 NPU 设备不存在或 torch_npu 未正确初始化
- **THEN** 系统报告该设备不可用，MUST NOT 静默改用 CPU 或其它设备继续服务

### Requirement: 以内存音频直接发起转写
系统 MUST 直接以内存中的音频数据发起单段转写，MUST NOT 为每段转写创建临时音频文件。音频数据 MUST 以浮点采样数组形式传入处理器，MUST NOT 在磁盘上落地中间文件。

#### Scenario: 单段转写不产生临时文件
- **WHEN** 一个 VAD 段发起转写
- **THEN** 服务在该段处理期间不创建任何段级音频临时文件，转写结果与该段音频一一对应

#### Scenario: 音频采样率与数据形态
- **WHEN** 传入的音频为单声道浮点数组
- **THEN** 处理器按其自身规则完成特征提取，服务不因采样率或容器形态与业务语义不符而改变段边界

### Requirement: 语种参数按既有规则注入
系统 MUST 保留既有语种参数规则：`auto`、空串或未提交时 MUST NOT 指定具体语种，由模型自动识别；提交具体语种时 MUST 传入处理器，处理器接受语种全名或 ISO 简写。系统 MUST 锁定处理器代码及版本，验证当前安装 5.13.0 的 system hint 实现，MUST NOT 仅凭 latest 文档假设本机采用 assistant forced-language。响应中的语种 MUST 取模型实际识别结果，MUST NOT 回显请求参数。

#### Scenario: 未提交语种
- **WHEN** 客户端未提交 `language` 或提交 `auto`
- **THEN** 系统不指定语种，由模型自动识别，响应语种为识别结果

#### Scenario: 提交具体语种
- **WHEN** 客户端提交 `language=English` 或 `language=en`
- **THEN** 系统将该语种传入处理器，响应语种为模型实际识别结果

#### Scenario: 语种不被模型支持
- **WHEN** 提交的语种无法被处理器接受
- **THEN** 系统返回 `4009`，MUST NOT 降级为自动识别

### Requirement: 原始输出保持既有前缀格式
系统 MUST 使本地推理的原始输出与既有解析契约保持一致，即输出包含语种前缀与 `<asr_text>` 标记。既有解析器 MUST 能从本地输出中剥离该前缀并取出转写文本与识别语种，行为 MUST 与迁移前的外部服务返回一致。

#### Scenario: 本地输出带语种前缀
- **WHEN** 本地推理返回 `language Chinese<asr_text>识别文本`
- **THEN** 既有解析逻辑产出文本为 `识别文本`、语种为 `Chinese` 的分段

#### Scenario: 本地输出无有效语音
- **WHEN** 本地推理返回 `language None<asr_text>`
- **THEN** 该段不产出响应分段

### Requirement: 本地推理受并发闸门约束
系统 MUST 复用既有的三层并发闸门语义，其中段级并发上限限制单个音频内同时执行的推理任务数，全局请求并发上限限制所有音频合计同时执行的推理任务数。同一模型实例 MUST NOT 在前一次物理执行及必要设备同步、结果读取和清理完成前被再次调度；线程返回、超时或请求取消均不等于设备完成。经验证的微批内可包含多个独立逻辑段任务，但 MUST NOT 并发复用实例的可写状态。

#### Scenario: 单音频内段并发受限
- **WHEN** 单个音频的段数量超过配置的段级并发上限
- **THEN** 同时执行的推理任务数不超过该上限，其余段排队等待

#### Scenario: 全局并发受限
- **WHEN** 多个音频合计请求数达到全局上限
- **THEN** 新请求进入等待或按既有准入策略被拒绝，不超出配置上限

#### Scenario: 同一实例不并发执行
- **WHEN** 某模型实例正在执行一次推理
- **THEN** 该实例在本次设备计算及必要收尾完成前不会被再次调度，模型状态持续反映 busy；后续任务排队等待

### Requirement: 推理失败映射到既有错误码
系统 MUST 将本地推理的失败映射到既有对外错误码：模型不可用或加载失败对应 `4011`，推理执行失败或超时对应 `4012`，语种不受支持对应 `4009`。MUST NOT 引入新的对外错误码，MUST NOT 将推理失败伪装为「无人声」。

#### Scenario: 推理执行失败
- **WHEN** 推理过程中发生设备错误、显存不足或生成超时
- **THEN** 系统按配置的失败策略重试，重试耗尽后返回 `4012`，并记录可定位原因

#### Scenario: 模型不可用
- **WHEN** 模型加载失败或设备不可用
- **THEN** 系统返回 `4011`，MUST NOT 继续发起推理请求

#### Scenario: 失败不被误判为无人声
- **WHEN** 推理因错误失败
- **THEN** 响应错误码为 `4012` 而非 `4008`，两者语义保持可区分

### Requirement: 推理模型按需加载且状态可观测
系统 MUST 保持转写模型的懒加载特性：未触发转写能力时 MUST NOT 加载权重。状态接口 MUST 暴露转写模型的加载状态、设备标识与资源占用，MUST NOT 因查询状态而触发加载。

#### Scenario: 查询状态不触发加载
- **WHEN** 运维在尚无转写请求时查询状态接口
- **THEN** 响应报告转写模型未加载，且不产生权重加载动作

#### Scenario: 首次请求触发加载
- **WHEN** 首个转写请求到达
- **THEN** 系统加载权重并完成该次推理，后续请求复用已加载的模型

#### Scenario: 加载失败不影响服务启动
- **WHEN** 转写模型加载失败
- **THEN** 服务保持可用并对外报告模型不可用，其余健康能力仍可服务

### Requirement: 原生交付基线与性能候选分阶段验收
本 change MUST 先交付 Transformers + torch_npu 原生 eager 正确性基线，MUST NOT 仅凭一次前向成功称其性能最优。系统 MUST 使用可复算样本对比原生 eager、可用的图编译、长度分桶微批及隔离的锁定版 vLLM-Ascend 候选，记录质量、冷启动、稳态吞吐、P50/P95、HBM、共享卡干扰和维护成本。候选胜出时 MUST 先更新相关 spec 与交付架构决策，再实施架构替换，MUST NOT 以候选实验静默引入第二套生产后端。

#### Scenario: vLLM-Ascend 候选验证
- **WHEN** 评估历史版本的 Qwen3-ASR 昇腾实现
- **THEN** 在独立环境或镜像锁定 vLLM、vLLM-Ascend、模型 revision、HF 权重映射和必要补丁，不修改 conda asr；核对停止维护风险、raw 输出、语种和错误码后记录比较结论

#### Scenario: 编译与微批比较
- **WHEN** 对原生基线启用编译或微批
- **THEN** 记录编译支持、首次编译和重编译成本、批大小及等待上限；每段独立输入输出和 VAD 边界保持不变，padding 使用经验证的有效 mask，不能通过拼接音频或忽略失败段提高统计吞吐

#### Scenario: 超时或取消时设备仍在执行
- **WHEN** 请求超时、取消或重复取消，而已启动的推理尚未收尾
- **THEN** 实例及相关租约仍由原任务持有，必要设备同步和清理完成后只释放一次，再传播错误或取消；重试不能与尚未完成的原执行共享可写状态

#### Scenario: 当前处理器语言行为复验
- **WHEN** 锁定目标环境的 processor 版本并执行 auto、空串、全名、ISO 码、非法语种及提示与音频语种不一致的用例
- **THEN** 保存实际提示构造和原始输出，确认识别语种来源；不能将 latest 文档或请求参数回显冒充本机模型识别结果，任何语义变更先修订契约
