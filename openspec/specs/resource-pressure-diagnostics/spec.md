# resource-pressure-diagnostics Specification

## Purpose
定义 ASR 服务在本地模型、VAD worker 和多路音频并发下的资源压力观测、受控验证和归因报告能力，帮助运维在发生 Swap、显存不足或请求卡顿前停止升压，并为后续内存释放、队列调度和实例规模优化提供证据。

## Requirements

### Requirement: 采集统一资源快照
诊断工具 MUST 以统一时间戳采集 SeaCraftASR、VAD worker、Qwen-ASR、主机内存、Swap、GPU、线程、文件描述符和服务缓存状态，并保存可复算的结构化记录。

#### Scenario: 采集运行中快照
- **WHEN** 诊断测试正在处理请求
- **THEN** 记录后端 PID 存活状态、VAD worker 数量、RSS/PSS、`VmSwap`、`MemAvailable`、Swap 增量、GPU 显存与利用率、缓存文件数量和端口健康状态

#### Scenario: 区分模型与请求资源
- **WHEN** 模型加载、音频并发或段级并发发生变化
- **THEN** 快照能按测试阶段关联模型池实例、模型池等待、请求数和资源峰值，不能只记录进程总 RSS

### Requirement: 按阶段受控升压
诊断测试 MUST 跳过已确认正常的 VAD-only A 项，并按模型单独加载、模型同时加载、2/4/8 路音频和段级并发档位逐级升压；前一阶段未通过安全检查时 MUST 不进入下一阶段。

#### Scenario: 逐级进入下一阶段
- **WHEN** 当前阶段所有请求完成且冷却期间资源指标保持稳定
- **THEN** 测试控制器才允许启动下一档并发，并保留当前阶段的配置和结果

#### Scenario: 阶段失败停止升压
- **WHEN** 当前阶段出现资源红色告警、后端异常或请求失败门槛
- **THEN** 控制器停止发送新请求，不再重试同一压力档位，并将该阶段标记为失败

### Requirement: 执行资源安全闸门
诊断测试 MUST 设置黄色告警和红色终止条件；红色条件触发后 MUST 停止新请求、等待可回收任务并优雅停止 SeaCraftASR，MUST NOT 停止或重启 Qwen-ASR。

#### Scenario: Swap 或内存压力终止
- **WHEN** 测试期间 Swap 增量超过阈值、`si/so` 持续非零或可用内存低于安全水位
- **THEN** 测试立即停止升压并终止当前批次，保存终止前后的资源快照和日志

#### Scenario: GPU 或进程异常终止
- **WHEN** GPU 剩余显存低于安全水位、出现 OOM、后端健康检查失败或 VAD worker 异常退出
- **THEN** 测试停止提交请求，保留现场信息并确认 SeaCraftASR 进程树、端口和缓存状态可回收

### Requirement: 保留请求和模型池关联指标
诊断结果 MUST 记录每个请求的开始时间、结束时间、耗时、错误码、重试和有效段数量，并关联 Qwen、CAM++、emotion2vec 的等待与推理耗时。

#### Scenario: 定位请求落后环节
- **WHEN** 某批次的 p95 明显高于 p50
- **THEN** 报告能比较 Qwen 等待、CAM++ 等待、emotion2vec 等待、VAD、裁剪和总耗时，指出主要排队位置

### Requirement: 输出资源压力归因报告
报告 MUST 区分模型常驻内存、音频与段级缓冲增长、请求后未释放、Swap 换页和 GPU 算力争用，并给出对应的后续优化方向和安全并发建议。

#### Scenario: 模型常驻内存过高
- **WHEN** 单路完整模型阶段已接近内存安全水位
- **THEN** 报告建议减少实例、拆分设备或增加内存，并明确并发升压不是解决方式

#### Scenario: 并发缓冲或释放异常
- **WHEN** 单路稳定而多路阶段内存随并发增长，或连续请求后 PSS 持续增长
- **THEN** 报告分别指向在途音频/段缓冲、对象引用或缓存清理方向，不将其误判为模型权重增长

#### Scenario: GPU 算力争用
- **WHEN** 主机内存和 Swap 稳定但 GPU 利用率长期饱和且模型等待增加
- **THEN** 报告将问题归因于同卡算力争用，并建议调整实例数量、设备分配或模型调度

### Requirement: 测试结束后验证回收
每个测试阶段结束或终止后 MUST 验证 SeaCraftASR 请求已排空、VAD worker 无孤儿进程、服务缓存回到基线附近、8085 端口状态可解释，并记录 Qwen 8806 仍保持运行。

#### Scenario: 正常阶段结束
- **WHEN** 一个阶段的全部请求完成
- **THEN** 记录冷却期资源值、缓存差值、进程树和端口状态后才允许下一阶段

#### Scenario: 异常阶段终止
- **WHEN** 红色安全闸门终止阶段
- **THEN** 保存终止现场，停止后续测试，并确认没有继续向已异常的后端发送请求
