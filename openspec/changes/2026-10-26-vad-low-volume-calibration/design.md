# Design

## Context

现有 worker 只向 FunASR 传递 `max_single_segment_time`、`max_end_silence_time` 和 `speech_noise_thres`。FunASR 的 `decibel_thres`、`snr_thres` 默认均为 `-100`，当前链路没有有效的响度门限；`speech_noise_thres` 是模型后验差值阈值，不是 dBFS 阈值。

请求上下文已经保留完整 `audio_tensor`、采样率和临时音频路径，VAD 输出段在进入 Qwen 前经过 `detect_segments()`；因此可以在不改变 Qwen 接口的情况下计算段级响度并丢弃无效段。参考标注解析后共有 658 个区间，其中 46 个为细小声音，已有实测显示后验阈值升至 `0.95` 仍得到 664 个 VAD 段。

## Goals / Non-Goals

**Goals:**

- 用同一套统计口径得到 46 个细小声音区间的时长、RMS/峰值 dBFS、VAD 后验和上下文特征。
- 让模型能量门限、SNR 和用户可理解的段级 RMS 门限都可配置，并保证每个 worker 使用同一组参数。
- 用可重复的粗扫与局部细扫选择候选值，以细小声音抑制率、标注区间无识别内容和正常语音保留率共同验收。
- 在 Qwen 请求前完成过滤并记录原因，保持保留段的时间轴和响应字段不变。

**Non-Goals:**

- 不修改 FSMN-VAD 或 Qwen-ASR 模型权重，不引入自动增益、降噪或新的音频编码链路。
- 不把单个参考音频的最优阈值直接当作所有部署环境的普适值；最终配置必须保留数据来源和回归报告。
- 不在没有可行指标结果时强行提高阈值；无单阈值时转为组合规则并明确报告。

## Decisions

### 1. 以声音大小为主，保留模型门限和段级 dBFS 门限

新增以下 `[qwen_asr]` 参数，默认值保持当前行为，避免升级后静默漏掉正常小声语音：

- `vad_decibel_thres`：传给 FunASR 的帧级 `decibel_thres`，单位为 FunASR 的 log 能量值，不冒充 dBFS。
- `vad_snr_thres`：传给 FunASR 的帧级 SNR 门限。
- `vad_low_volume_rms_dbfs_thres`：VAD 段级 RMS dBFS 门限，低于该值的候选段进入低音量判定。
- `vad_low_volume_filter_enabled`：段级规则开关，默认关闭直到参考音频扫描选出部署值。

选择声音特征作为第一优先级，是因为用户要过滤的是“声音过于小”，而不是“时长过短”。FunASR 的帧级 log 能量与用户熟悉的 dBFS 不同，因此同时保留模型门限和段级 RMS；模型门限先抑制低置信度帧，RMS、SNR 和低能量帧比例再阻断最终无效请求。音频段时长只作为后续兜底条件，不参与第一轮候选搜索。

### 2. 统计使用统一的 10 ms 帧和标注区间

统计工具从音频张量按 10 ms 帧计算 RMS dBFS、峰值 dBFS，并记录每个标注区间的时长、帧数、分位数和相邻上下文。VAD 诊断钩子记录每帧 `speech_prob - noise_prob`、模型能量、帧状态和所属最终 VAD 段。

报告至少包含：总时长、标注/对照数量、每段明细、P10/P50/P90/P99、候选阈值、细小声音命中/抑制率、标注区间内识别内容、未标注保留率、VAD 段数、丢弃段数和 Qwen 请求数。RMS dBFS 只用于能量规则，不能替代区间命中和识别内容指标。

### 3. 阈值搜索采用分位数粗扫和边界细扫

搜索先从标注与对照分布的分位数生成粗粒度候选：标注区间的 P50/P75/P90/P95，以及对照区间的 P01/P05/P10/P25；dBFS 候选限制在 `[-80, 0]`，模型门限限制在 FunASR 支持范围。若候选落在两类分布的交叠区，再以 0.5 dB 或 0.01 后验步长围绕交叠边界滑动，直到达到最小步长或找到可行值。

默认验收目标为细小声音抑制率不低于 95%、标注区间无有效识别内容、未标注区间保留率不低于 95%，目标值可由扫描命令覆盖。候选选择优先满足三项约束，再选择正常语音保留率最高且 Qwen 请求数较少的值；报告保留完整 Pareto 候选，不只输出一个黑盒数值。

### 4. 端到端过滤在 Qwen 请求之前执行

`detect_segments()` 先得到 VAD 候选，再根据音频张量计算段级特征。满足低音量规则的段被标记为 `low_volume` 并丢弃，丢弃数量和阈值写入请求日志；只有剩余段进入惰性裁剪和 Qwen 并发队列。过滤后为空时沿用现有 `4008` 响应。

保留段的 `bg`、`ed` 不做平移或合并，现有 `min_segment_duration_s` 继续作为既有通用过滤，但不作为本次低音量标定的主依据。段级低音量规则只删除整个候选段，不能把长段内部重新切开；若扫描证明细小声音通常嵌在长段中，则先启用“RMS/SNR + 低能量帧比例 + 连续有效语音帧”组合规则，而不是扩大 RMS 阈值误伤整段讲话。

### 5. 无单阈值时的处理

当完整搜索空间内不存在同时满足三项目标的单一声音门限，报告必须标记无可行单阈值，并列出最接近的候选、区间内识别文本及误伤样本。下一轮仅在统计交叠边界附近继续细扫；若仍无解，采用声音组合规则：段 RMS 门限、SNR、低能量帧占比和连续有效语音帧共同判定。只有声音组合规则仍无解时，才进入第二阶段评估音频段时长条件。所有规则同样经过三项指标验收，不能用“段数明显减少”代替。

## Risks / Trade-offs

- **低声真实讲话被误删** → 默认关闭新段级开关；以未标注保留率作为硬约束，并在报告保存被丢弃段的时间和响度。
- **麦克风增益改变 dBFS 分布** → 配置文档记录采样率、声道和采集设备；部署前重新运行扫描，不直接复制参考音频阈值。
- **VAD 端点扩展掩盖低音量声音** → 同时报告逐帧判定、段级命中和区间内识别内容，必要时启用低能量帧比例与连续有效帧规则；不先用时长条件掩盖声音特征问题。
- **每段计算 RMS 增加 CPU 开销** → 优先复用已加载的 `audio_tensor`，只对 VAD 候选区间计算；在报告记录额外耗时。
- **标注格式变化导致错误推荐** → 启动扫描时断言 46 个标注段并报告无法解析对象，解析失败不得继续输出部署建议。

## Migration Plan

1. 先发布参数读取、统计和扫描入口，保持新段级过滤关闭，运行短音频和参考音频基线。
2. 在目标环境完成粗扫和统计边界细扫，选择同时满足抑制率、区间无识别内容和正常语音保留率的声音候选；若无单阈值，先实现并验证声音组合规则。
3. 只有声音组合规则仍无解时，才评估加入音频段时长条件，并单独记录其误伤风险。
4. 将推荐值写入本地/容器配置并重启，检查 worker 状态、VAD 段数、丢弃原因、标注区间识别内容和 Qwen 请求数。
5. 若正常语音保留率或标注区间识别内容指标不达标，回退到上一候选或关闭段级开关；回滚不改变 `speech_noise_thres` 的既有语义。

## Open Questions

- 生产环境默认抑制率和保留率目标是否需要从 95% 调整为业务指定值；该问题不影响统计和扫描接口，可在验收阶段确定。
