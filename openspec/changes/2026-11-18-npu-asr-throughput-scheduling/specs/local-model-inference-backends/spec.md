## MODIFIED Requirements

### Requirement: 输入输出边界必须保持模型和业务语义
系统 MUST 按经验证输入契约准备输入并读取完整输出。有效时长不足0.3秒的段 MUST 在模型分发前移除，不调用Qwen、CAM++或emo且不进入响应。请求说话人能力时，0.3秒及以上段 MUST 实际执行CAM++，成功embedding MUST 参与原聚类，不再仅因不足1秒而丢弃或被就近标签覆盖。emotion2vec MUST 仅在1～10秒闭区间实际推理，区间外有效段按既有规则记“平淡”。原FP32策略、聚类阈值和情绪映射 MUST 保留，非法或越界输入明确记录，不静默改变段边界。

#### Scenario: CAM++ 特征与输出
- **WHEN** CAM++处理0.3秒及以上且符合输入支持的VAD段
- **THEN** 使用与FunASR一致的80维、按段去均值fbank，输出192维embedding并参与聚类，不跨VAD段合并；0.3至不足1秒的成功embedding不会因旧短段筛选被丢弃

#### Scenario: emotion2vec 完整分类
- **WHEN** emotion2vec处理1～10秒的片段
- **THEN** 完整输出含分类概率，标签顺序与现有业务映射一致，不以中间representation代替最终分类

#### Scenario: profile 越界
- **WHEN** 需要推理的输入超出模型允许的长度范围
- **THEN** 记录可定位失败，不擅自截断、补零、拆段；普通段级失败与实例不可用按既有错误分层处理

#### Scenario: 299毫秒段与300毫秒段
- **WHEN** 按有效采样数计算的段时长分别为299、300、301毫秒且请求说话人与情绪
- **THEN** 299毫秒段在三个模型分发前移除；300和301毫秒段执行Qwen与CAM++、emo不推理并直接记“平淡”，边界不使用响应两位小数时间判断

#### Scenario: 999毫秒段与1000毫秒段
- **WHEN** 有效段时长分别为999、1000、1001毫秒且请求说话人与情绪
- **THEN** 三段均实际执行CAM++；999毫秒的emo直接“平淡”，1000和1001毫秒实际推emo，分类及原业务映射保持不变

#### Scenario: emotion2vec十秒边界
- **WHEN** 有效段分别为9999、10000、10001毫秒且请求情绪
- **THEN** 前两段实际推emo，10001毫秒段不推emo并记“平淡”；未请求情绪时各段emotion仍为null
