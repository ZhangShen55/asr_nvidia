## 3. 正式轮次及条件性扩展

每轮八请求共同起跑并同时保持最多八完整音频，所有权与上游窗口不改变。顺序B0、M2、S1；每轮之间完整收尾、冷却和共享资源复查。M2与S1均只改变自己的因素。未触发条件的轮次在decision-log.json记录原因，不标“已测”。

- B0：当前单模型continuous16/128基线，只加同等诊断控制器。旧2/8为历史参考，本轮仍用新的336停止规则，不延长到420补齐参考。
- M2：双模型、每个固定负责四音频、各最多64；八音频总在途仍128，每音频仍16。若预计或实测≥336停止，关闭该分支。若只是200～336之间改善，只有实际阶段证据支持增加模型有望接近200且资源余量满足，才考虑M4/M8；不得用线性倍增推算充当可行证明。
- S1：单模型16/128，仅独立裁剪执行器及专用有界发送队列；保持模型逻辑、KV算法与prefill策略不变。M2收益不足不自动证明S1无效，但资源/收尾红色故障要求整个批次停止并先反馈。
- M4/M8/MS：有条件实验；必须事先记录扩展理由、变量表、预估HBM余量，实际证据优先。8/64窗口缩小、decode物理上限32等不是本轮基础矩阵，不能顺带改动。
- 冻结有望目标的候选后，追加至总计三轮有效真实v3复验；任何一轮触发停止/质量/资源问题即不能给积极结论，不为凑成功次数丢弃失败轮。

## 4. 200秒目标和提前停止

T_batch从八请求共同起跑至最后一个完整HTTP响应接收，包含上传/准备。主目标8/8且T_batch≤200秒。超过200秒仍能有局部收益，但不能算达到保守目标线；336秒尚未8/8必须硬停止。

提前预测按design中冻结规则：全八有效VAD段数已知、t≥90秒、连续60秒进度后，每30秒评估，保留较快吞吐和25%加速余量，分别评估八条剩余进度与可能尾部加速。连续两次可信偏乐观ETA≥336即终止。进度缺失/共享变化/启动抖动/自然段难度分布差异导致不可信时，不以全局平均段数线性外推作早停依据，等待可信证据或336硬截止。

预测快照必须保存t、每音频总段/已完成/在途、30/60秒吞吐、输入时长和生成token分布、尾部假设、各音频ETA、整轮ETA、可信度、规则版本及触发原因。禁止把预测叫实测耗时或硬件下界；早停后及时给出阶段性问题反馈，再完成有界收尾。

红色资源条件优先于时间规则：可用HBM<8GiB、OOM、持续换页/主机安全水位不足、服务或worker异常；禁止对共享服务采取动作。大进程档仅加载成功不算容量通过，必须看推理峰值。

## 5. 统计与质量

每轮保存：处理完成率、严格无警告成功率、非空文本请求数、warning/fatal/取消/删失、全轮墙钟、每请求耗时、全8或完成子集P50/P95及n。完整轮T_batch与关闭耗时分列；暖身不混入正式统计。基线/候选未完成时精确整轮提速比为null，不以两条子集或ETA冒充8条完成时间。

对齐源SHA、VAD边界及原段ID，输出可搜索old/new完整文本、字段变化、新增/缺失、语种、复读和截断差异。输出为空但有warning不算无异常成功。无完整配对时diff=null；已有模型输出只作相对参考。明显新增漏字/错语种、重复或截断须定向复核，保留听音/参考来源和未决项；质量证据不足就不提供整体可行结论，不编造人工准确率。

## 6. 收尾和交付

每轮finally停止追加、等待owned工作安全终态、关闭全部测试父子进程；登记整体关闭期限并处理重复取消。记录normal/forced及退出码，不把强制回收当正常。核对PID出生身份消失、端口连续至少5秒未监听、私有PCM为空、既有服务保持，保留日志与副本。停止触发到资源释放的耗时另列。

预期证据目录：原始`logs/qwen-200s-feasibility-<run-id>/`；可提交报告`docs/qwen-200s-feasibility-20261123/`。交付包括baseline-manifest.json、experimental-patches/、各轮run/requests/responses/status/phase/stop/shutdown、decision-log.json、transcript-diff.json/html、cleanup-verification.json、REPORT.md。当前提案仅规划这些产物，不能预先生成成功结果。

结论分级：

1. **目标可行**：同一冻结候选三轮有效正式测试均8/8≤200秒，质量复核与正常回收通过。
2. **局部改善未达目标**：有真实HTTP改善但未达到200秒或缺稳定复验，仅给剩余差距。
3. **该候选收益不足**：可信预计≥336或实际336未完成，停止该分支并报告证据；不泛化成硬件绝对不可行。
4. **证据不足/实验无效**：共享干扰、漂移、计数/归属错误、预测无效或质量资料不足；列明边界，不进入正式改造。

负结论在取证与正常收尾齐备时也是本轮验证的完成；若清理失败，清理任务仍未完成。未测扩展必须有闸门决策记录。正式改造、默认推广及旧change归档均不在本轮。
