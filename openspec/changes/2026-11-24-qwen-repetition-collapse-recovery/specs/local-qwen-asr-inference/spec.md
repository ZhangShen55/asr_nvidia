# Spec Delta

## MODIFIED Requirements

### Requirement: 多owner段级生成异常保留恢复与警告
continuous多owner MUST 保留逐段在线复读保护和生成后修复。对已确认的异常尾部复读，MUST 保留前文并将循环折叠为一次出现，不因恢复短句不足8汉字或4英文单词丢弃；纯填充词、空正文、无效前缀仍明确警告，非复读长度耗尽仅保留既有完整前缀。所有恢复继续其它段，保留原边界及警告，不代表人工准确率；正常EOS、强调/结巴/教学重复、超时/取消/OOM/worker故障的原行为和错误分类不变，内部原始生成轨迹不对外暴露。

#### Scenario: 一个段异常而其余段正常
- **WHEN** 某owner中的一个段触发可恢复生成异常
- **THEN** 只终止并安全回收该段后续解码，保留可恢复文本及原因/动作/原段边界警告，其余段与其它owner继续；无法恢复段即使不进入segments也保留警告

#### Scenario: 全部段无法恢复
- **WHEN** 一个音频所有有效VAD段均为无法恢复的段生成异常
- **THEN** 返回空segments、completed_with_warnings及各段警告，不返回无人声4008，也不统计为严格无警告成功

#### Scenario: 正常重复和设备故障
- **WHEN** 音频存在保护集中的真实重复，或执行发生OOM、超时、取消、worker死亡
- **THEN** 前者不被简单禁止重复的规则误删；后者仍按既有基础设施失败及owned收尾契约处理，不转换为段警告成功

#### Scenario: 短前文及首次循环内容保留
- **WHEN** 某段已确认异常复读，正文是今天天气后连续输出很好，或整句今天天气很好重复
- **THEN** 沿原段边界保留今天天气很好，警告action为repetition_collapsed且recovered=true，不因短句字数丢弃

#### Scenario: 复读末尾是不完整循环单元
- **WHEN** 已确认的循环在一个重复单元中间被停止
- **THEN** 保留非循环前文和第一个完整循环单元，避免末尾残片造成循环起点旋转或多保留一份碎片
