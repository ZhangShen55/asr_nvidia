# Design

## Context

见proposal.md。现有suffix_repeat以去分隔符字符定位已确认尾部周期；恢复却删除所有副本。常规repair_repetition能折叠，但其长度门槛及全正文扫描不适合在线提前停止路径。

## Goals / Non-Goals

**Goals:** 仅对异常恢复中的已确认尾部循环，保留前文与首个完整单元，去除其余副本；中英短句不因8字/4词门槛丢弃。警告、原边界、取消/资源与错误契约保持。

**Non-Goals:** 不调在线阈值、VAD、实例数、配置，不重识别或覆盖历史课程JSON，不承诺原2.02秒段已找回或准确率认证。

## Decisions

- 只折叠suffix_repeat命中的尾部周期，避免通用全文折叠误伤前文的正常强调。按原字符位置保留第一单元和结尾标点；若生成停止在半个单元，向前按周期追溯真实起点，避免保留旋转残片。
- 循环恢复采用非空有效文字判据并沿用纯填充词排除，去掉仅该路径的8字/4词门槛。无循环的length_limit仍按原完整句/字数规则恢复。
- action采用已有v3测试桩使用的repetition_collapsed，reason保持repetition_stop或length_limit；每次恢复仍有警告。无效语言前缀及基础设施错误不进入文本兜底。
- 配置审计独立只读，追踪loader/工厂/运行分支/部署入口，不将仅当前关闭的参数误称死配置。

## Risks / Trade-offs

- 保留一次模型循环内容不保证与音频一致 → 保持completed_with_warnings，不宣称严格无异常或人工准确率。
- 正常重复误伤 → 正常EOS及在线检测完全不变，仅处理已进入异常恢复路径的尾部循环。
- 部分单元/英文空格/分隔符造成切割错误 → 明确中英、周期旋转、标点及前文不变的回归样例。

## Migration Plan

CPU隔离完整回归和continuous/v3契约验证后提交推送；部署源码需重启，镜像/保护构建在后续构建纳入。回退本次实现提交可恢复旧策略，历史证据/JSON不修改。无新参数或依赖。
