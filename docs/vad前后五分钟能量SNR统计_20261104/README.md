# 45 个课堂音频前后五分钟 VAD 段能量与 SNR 统计

## 统计范围

- 音频目录：`/home/zhangs/workspace/asr_nvidia/test/audio_file/音频文件`
- WAV 数量：45 个，均为 16 kHz 音频，总时长约 37.89 小时。
- VAD：项目当前 FSMN-VAD 模型 `model/speech_fsmn_vad_zh-cn-16k-common-pytorch`。
- 当前配置：`vad_speech_noise_thres=0.6`、`vad_decibel_thres=-100`、`vad_snr_thres=-100`、`min_segment_duration_s=0.3`。
- 前五分钟：与 `[0, 300)` 秒有重叠的 VAD 段。
- 后五分钟：与 `[音频时长-300, 音频时长)` 有重叠的 VAD 段。
- 指标按完整 VAD 段计算；跨窗口边界的段仍保留，并在明细中标记 `crosses_window_boundary` 和窗口内重叠时长。

本次没有修改配置，也没有启用段级低音量过滤。共得到 4,152 个窗口内 VAD 段：前五分钟 1,960 段，后五分钟 2,192 段。

## 总体分布

| 窗口 | VAD 段数 | 段时长合计 | RMS P10 / P50 / P90 (dBFS) | 估计 SNR P10 / P50 / P90 (dB) |
|---|---:|---:|---|---|
| 前 5 分钟 | 1,960 | 6,689.1 s | -44.52 / -28.80 / -16.20 | 10.96 / 24.78 / 45.52 |
| 后 5 分钟 | 2,192 | 7,863.0 s | -44.52 / -24.74 / -12.94 | 10.16 / 24.12 / 46.47 |

后五分钟的 RMS 中位数比前五分钟高约 4.06 dB，说明这批样本的音量分布存在时间段差异，不能用单个音频的前五分钟直接代表整段录音。

这里的“估计 SNR”按项目诊断口径计算：

```text
估计 SNR = VAD 段 RMS dBFS - 该段 10 ms 帧 RMS dBFS 的 P10
```

它用于比较段之间的相对噪声情况，**不是** FunASR 内部 `snr_thres` 的同单位观测值。

## 阈值模拟

以下比例是对已经切出的 VAD 段做离线统计，表示“如果使用段级 RMS/SNR 过滤，会有多少段被候选规则命中”。它不等价于把同样数字填入 `vad_decibel_thres` 或 `vad_snr_thres` 后重新切分的结果。

| 候选规则 | 前五分钟命中段数/比例 | 前五分钟命中段时长比例 | 后五分钟命中段数/比例 | 后五分钟命中段时长比例 |
|---|---:|---:|---:|---:|
| RMS < -50 dBFS | 102 / 5.20% | 1.29% | 95 / 4.33% | 1.37% |
| RMS < -46 dBFS | 174 / 8.88% | 2.33% | 183 / 8.35% | 3.31% |
| RMS < -44 dBFS | 205 / 10.46% | 2.81% | 235 / 10.72% | 4.57% |
| RMS < -42 dBFS | 252 / 12.86% | 3.60% | 280 / 12.77% | 5.66% |
| RMS < -41 dBFS（当前段级候选值） | 278 / 14.18% | 4.08% | 303 / 13.82% | 6.10% |
| RMS < -40 dBFS | 322 / 16.43% | 5.21% | 330 / 15.05% | 6.49% |
| 估计 SNR < 6 dB | 50 / 2.55% | 0.55% | 50 / 2.28% | 0.79% |
| 估计 SNR < 9 dB | 127 / 6.48% | 1.83% | 156 / 7.12% | 2.58% |
| 估计 SNR < 12 dB | 245 / 12.50% | 4.70% | 313 / 14.28% | 6.77% |

从数量和时长看，RMS `< -41 dBFS` 会命中约 14% 的 VAD 段，但只覆盖约 4.1%～6.1% 的 VAD 段时长；这说明命中的大部分是短段。这个结果可以作为候选筛查范围，不能直接说明这些段都是无效语音。课堂中的低声授课、远处说话和语气词也可能落入该范围。

## 对 `vad_decibel_thres` 和 `vad_snr_thres` 的结论

当前两个配置均为 `-100`，保持 FunASR 原有行为。仅凭本次 RMS/SNR 统计，不建议直接把 `-41` 或 `6/9/12` 填入这两个配置：

1. `vad_decibel_thres` 是 FunASR VAD 的帧级 log 能量阈值，单位不是 WAV 常用的 dBFS；本报告中的 RMS dBFS 不能直接换算成该参数。
2. `vad_snr_thres` 也是 FunASR 的帧级 SNR 判定参数，本报告的估计 SNR 采用段级噪声底估计，单位和计算过程不同。
3. 修改这两个参数会改变 VAD 的起止边界和段数，不能用“当前已切出的段有多少低于某值”预测修改后的最终保留率。
4. 已有测试表明，提高 `vad_speech_noise_thres` 不能可靠消除课堂细小声音；需要真值标注才能判断漏掉有效授课的风险。

如果目标是过滤已经切出的低能量候选段，当前项目已有更可控的段级路径：`vad_low_volume_rms_dbfs_thres` 配合 `vad_low_volume_filter_enabled`。这条路径的单位就是 RMS dBFS，适合先做 `-41/-42/-44 dBFS` 的离线候选听查，并同时检查正常语音保留率、细小声音抑制率和 Qwen 文本内容。SNR 可以作为第二条件，但应使用项目段级统计口径重新标定，不能直接套用 FunASR 的 `vad_snr_thres`。

建议的下一步是：先从明细中抽取 `rms_dbfs < -41` 或 `estimated_snr_db < 9` 的段做人工听查，分为“无关环境音、有效低声语音、边界混合、无法判断”，再决定是否启用段级过滤。没有这一步，不建议仅凭本次分布调整生产 VAD 帧级阈值。
