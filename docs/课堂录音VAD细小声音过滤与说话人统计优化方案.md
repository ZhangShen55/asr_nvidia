# 课堂录音 VAD 细小声音过滤与说话人统计优化方案

## 1. 背景与目标

课堂录音的目标是转写老师和学生之间的有效对话。当前 VAD 会把咳嗽、清嗓、敲击、翻页、椅子摩擦、远处短促声音等细小声音判断为疑似语音，并将这些片段送入 Qwen-ASR，带来三个问题：

- 转写结果中出现本不需要的短词、拟声词或噪声内容；
- 无效片段增加 Qwen-ASR、CAM++ 和 emotion2vec 的推理量；
- VAD 分段数量增加，后续模型池排队时间变长。

本方案的目标是：

1. 尽量保留老师和学生的有效对话；
2. 在送入 Qwen-ASR 前过滤细小声音和环境噪声；
3. 对保留下来的有效对话进行说话人分析，估计参与对话的人数；
4. 避免使用“只保留老师声音”的规则，避免误删学生的有效发言。

## 2. 当前测试结论

在《理论计算机科学导论》录音上，JSON 中标注了 46 个“细小声音”。FireRedVAD 三个阈值的时间重叠结果如下：

| `speech_threshold` | VAD 分段数 | 与细小声音有任意重叠 | 未发生重叠 |
|---:|---:|---:|---:|
| 0.5 | 882 | 36/46（78.26%） | 10/46 |
| 0.6 | 893 | 32/46（69.57%） | 14/46 |
| 0.7 | 913 | 31/46（67.39%） | 15/46 |

`0.7` 在当前三组测试中抑制效果最好，但仍有 31 个标注与 VAD 分段发生重叠。因此，单纯提高 `speech_threshold` 不能解决问题。阈值提高后分段数反而增加、短段比例升高，说明它同时改变了边界和切分结构，不能按“阈值越高，分段越少”理解。

这里的“检测到”是时间区间重叠，不代表 VAD 能理解该片段是咳嗽、翻页或有效对话。VAD 只判断音频是否具有语音活动特征。

## 3. 推荐处理链路

```text
原始课堂录音
    ↓
FireRedVAD：高召回地产生候选片段
    ↓
候选片段后处理：时长、静音间隔、语音概率、上下文连续性
    ↓
环境声音过滤：咳嗽、敲击、翻页、摩擦、背景噪声
    ↓
Qwen-ASR：转写候选片段
    ↓
ASR 结果质量过滤
    ↓
CAM++ 声纹提取 + 聚类
    ↓
说话人分段、人数估计和结果合并
```

核心原则是：先判断“是不是值得转写的有效对话”，再判断“有效对话中有几个人”。CAM++ 不用于判断“是不是老师的声音”，否则会把学生的有效发言过滤掉。

## 4. 各阶段设计

### 4.1 FireRedVAD：负责候选召回

FireRedVAD 应主要承担候选片段召回，不能承担完整的语义过滤职责。初始验证可以使用 `speech_threshold=0.7`，但上线参数必须同时观察正常语音召回率和细小声音保留率。

候选片段应保留少量前后边界，避免切掉正常语音的起始辅音或结束音。边界 padding 不宜过大，否则会把邻近噪声重新带入 Qwen-ASR。

### 4.2 候选片段后处理

建议联合使用以下条件，而不是只按音量过滤：

- **最小时长**：过滤极短且孤立的片段；
- **语音概率**：要求超过阈值的帧数和平均概率同时达标；
- **静音间隔**：片段前后都是较长静音时，提高过滤等级；
- **上下文连续性**：靠近正常语音的短片段可以合并，完全孤立的短片段优先丢弃；
- **能量与信噪比**：作为辅助条件，不单独作为删除依据。

不能只使用固定音量阈值。远距离讲话、英文弱读和轻声回答可能音量较低，单纯按 RMS 或分贝过滤会误删有效课堂内容。

建议对以下参数做组合验证：

```text
speech_threshold = 0.7
min_speech_frame = 20 / 30 / 40
min_silence_frame = 20 / 30 / 40
merge_silence_frame = 0 / 10 / 20
```

每组测试都必须检查正常语音是否缺失，不能只看“细小声音减少了多少”。

### 4.3 环境声音过滤

对后处理留下的候选片段增加一个轻量的环境声音判断层，目标是识别：

- 咳嗽、清嗓；
- 敲桌、敲键盘；
- 翻书、翻页；
- 椅子移动、桌面摩擦；
- 门响、走动声；
- 风扇、空调和其他稳定背景噪声；
- 远处短促的非目标声音。

现成模型可以按以下顺序验证：

| 模型 | 适用场景 | 说明 |
|---|---|---|
| YAMNet | 快速验证环境声音类别 | 基于 AudioSet，部署和推理相对简单 |
| PANNs / CNN14 | 环境声音类别较多 | 可提取 AudioSet 预训练特征，也可用于后续微调 |
| AST | 需要更高分类能力 | 计算量和部署复杂度更高 |

第一阶段不建议立即训练专用模型，应先用 YAMNet 或 PANNs 在真实课堂片段上验证。如果现成模型无法区分课堂中的特定噪声，再训练“有效对话 / 细小声音”分类器。

### 4.4 Qwen-ASR 结果质量过滤

Qwen-ASR 之后可以增加结果质量判断，作为音频过滤的补充：

- 无文本或文本极短；
- 平均置信度低；
- 输出重复字符或异常标点；
- 仅输出“嗯、啊”等不具备有效语义的内容；
- 模型提供无语音概率时，概率达到阈值则丢弃。

该层不能替代前置过滤，因为音频已经进入 Qwen-ASR。它的主要价值是清理前置规则无法判断的边界片段。

### 4.5 CAM++：用于说话人分析

CAM++ 的职责是对有效对话进行说话人分析，而不是筛选老师声音。建议流程是：

1. 对通过前置过滤并完成转写的有效片段提取 CAM++ 声纹向量；
2. 使用 AHC 或谱聚类将相近声纹归为同一说话人；
3. 为每个聚类分配 `spk_0`、`spk_1` 等标签；
4. 合并相邻且属于同一说话人的片段；
5. 统计本次课堂录音中出现的说话人数量。

CAM++ 只提供声纹特征，不能独立完成准确人数统计。多人同时说话时还需要重叠语音检测，此时人数统计应标记为估计值。说话人聚类应在有效对话过滤后执行，避免把咳嗽、敲击等片段送入声纹聚类。

## 5. 训练数据建议

如果现成环境声音模型不满足课堂场景，建议按阶段准备数据：

| 阶段 | 数据规模 | 用途 |
|---|---:|---|
| 初步验证 | 每类 20～50 段 | 判断现成模型是否覆盖主要噪声 |
| 第一版训练 | 每类 200～500 段，每段 1～5 秒 | 训练课堂场景二分类器 |
| 稳定上线 | 每类 1000 段以上，覆盖多个教室和录音设备 | 提高跨课堂泛化能力 |

至少应包含以下类别：

```text
有效对话
咳嗽/清嗓
敲击声
翻页声
椅子或桌面摩擦
门响和走动声
风扇/空调/背景噪声
远处短促说话声
```

训练集、验证集和测试集应按课堂录音或录音设备划分，不能把同一段录音的相邻切片随机分到不同集合，否则评估结果会偏高。

## 6. 评估指标

不能只比较 VAD 分段总数，应同时记录：

| 指标 | 目的 |
|---|---|
| 老师和学生有效语音召回率 | 防止误删正常对话 |
| 细小声音保留率 | 衡量无效声音过滤效果 |
| Qwen-ASR 输入段数量 | 衡量前置过滤收益 |
| Qwen-ASR 总耗时 | 衡量实际推理成本下降 |
| CAM++/emotion2vec 输入段数量 | 衡量后续模型负载下降 |
| 转写文本缺失率 | 检查是否误删有效内容 |
| 平均段长、P50、P95 和短段比例 | 观察分段粒度变化 |
| 说话人聚类纯度和人数误差 | 检查说话人统计质量 |

推荐的初始上线目标是：有效对话召回率不低于 98%，再逐步降低细小声音保留率。对于无法确定的边界片段，可以进入低优先级或二次处理队列，而不是直接使用激进规则删除。

## 7. 分阶段落地计划

### 第一阶段：无模型训练改造

- 保留 FireRedVAD 作为候选召回；
- 增加时长、静音间隔、语音概率和上下文后处理；
- 对 `speech_threshold` 与后处理参数做网格测试；
- 统计有效语音召回率和细小声音保留率。

### 第二阶段：验证现成环境声音模型

- 使用 YAMNet 或 PANNs 对候选片段分类；
- 在真实课堂录音上评估咳嗽、敲击、翻页等类别；
- 评估过滤后 Qwen-ASR 总耗时和文本缺失率。

### 第三阶段：必要时训练课堂专用分类器

- 建立课堂噪声和有效对话标注集；
- 按课堂或设备划分训练集、验证集、测试集；
- 以有效对话召回率优先调节分类阈值；
- 保留不确定样本用于后续迭代。

### 第四阶段：说话人分析

- 对过滤后的有效对话提取 CAM++ 声纹；
- 增加聚类和相邻片段合并；
- 输出说话人标签、人数估计和置信度；
- 对多人重叠说话单独标记，不把估计人数当作绝对事实。

## 8. 结论

最适合当前课堂转写场景的方案是“高召回 VAD + 候选后处理 + 环境声音过滤 + Qwen-ASR 质量过滤 + CAM++ 说话人聚类”。

CAM++ 不用于只保留老师声音，而用于在老师和学生的有效对话保留下来之后，分析说话人身份和人数。环境声音分类器优先使用 YAMNet 或 PANNs 做现成模型验证，只有验证不足时才训练课堂专用分类器。这样可以降低无效片段进入 Qwen-ASR 的比例，同时保留课堂中老师和学生的有效对话。
