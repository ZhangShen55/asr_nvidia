# 固定 VAD 4 Worker、4 路并发复测报告

- 日期：2026-10-27
- 接口：`POST /v2/seacraft_asr`
- 音频：`test/audio_file/教师1.aac`
- 音频时长：3303.28 秒（约 55.05 分钟）
- 并发：4 路完整音频
- `showSpk=true`，`showEmotion=true`
- VAD：CPU，服务启动时固定预热 4 个 worker
- 本地模型：CAM++ 4 实例、emotion2vec 4 实例，全部在 `cuda:0`
- Qwen-ASR：`127.0.0.1:8806`，测试期间保持运行

固定池配置：

```toml
vad_pool_size = 4
vad_pool_max = 4
```

## 3. 阶段耗时

4 个成功请求的服务日志统计：

- VAD 阶段：中位数 18.347 秒，范围 15.061～18.700 秒。
- 分段处理：中位数 136.036 秒。
- CAM++：中位数 101.090 秒/请求。
- emotion2vec：中位数 39.203 秒/请求。
- 总处理耗时：中位数 157.485 秒。

## 4. 固定池状态验证

服务启动时 4 个核心 worker 全部预热完成，测试期间保持：

```json
{
  "workers": 4,
  "pool_size": 4,
  "pool_max": 4,
  "busy": 0,
  "waiting": 0
}
```

没有出现扩容 worker。CAM++ 和 emotion2vec 均为 4/4 实例加载成功，`failed_instances=0`；测试结束 GPU 0 显存约 28.4 GB / 49.1 GB。

## 5. 与固定 16 路结果对比

| 指标 | 固定 4 VAD / 4 路 | 固定 16 VAD / 16 路 |
| --- | ---: | ---: |
| 成功率 | 4/4（100%） | 16/16（100%） |
| 墙钟时间 | 188.467 秒 | 686.477 秒 |
| 音频吞吐 | 1.273 路/分钟 | 1.398 路/分钟 |
| VAD P50 | 18.347 秒 | 39.144 秒 |
| VAD 排队失败 | 0 | 0 |

4 路和 16 路均能稳定完成全部请求。16 路整体吞吐略高，但 VAD 阶段耗时随并发增加；继续提高并发需要结合 CPU 线程争用和 GPU 分段处理能力评估。

测试结束后已关闭 8084，Qwen-ASR 的 8806 端口仍在监听。
