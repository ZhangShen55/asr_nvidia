## 结果与证据

- 三档均 HTTP 成功，`totalFailedTasks=0`；每个请求 VAD 都产出 395 个有效段并发起 395 次 Qwen 请求，响应段数为 380（纯标点/空文本卫生处理后）；测试结束时固定 VAD 池为 8/8 成功、busy=0、waiting=0。
- `/tmp/seacraft_asr` 服务专属缓存审计为空；源文件由请求 finally 清理，生产段处理没有段级 WAV 文件。
- 控制台没有逐段 `httpx` 成功访问行；文件日志保留完整 HTTP 访问记录。进度条按 `395/N` 段推进，8 路各自独立。
- 1 路到 4 路吞吐提高，但 8 路 GPU0 达到 100% 峰值并出现争用，P50 上升到 103.979 秒；该结果反映 Qwen/裁剪共享 GPU 与请求并行带来的尾延迟。
